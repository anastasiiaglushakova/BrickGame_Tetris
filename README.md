# BrickGame v1.0 — Tetris

**BrickGame Tetris** — реализация классического Тетриса для терминала с использованием библиотеки `ncurses` и логикой, оформленной в виде конечного автомата. Проект разделён на две части: библиотека, реализующая логику игры, и пользовательский интерфейс на основе терминала.

---

## 🧹 Особенности игры

* Полноценная реализация механик Тетриса:

  * Вращение фигур
  * Перемещение по горизонтали
  * Мгновенное падение вниз
  * Уничтожение заполненных линий
  * Показ следующей фигуры
  * Завершение игры при достижении верхней границы
* Все 7 классических фигур (I, O, T, S, Z, L, J)
* Поддержка управления, имитирующего оригинальную консоль BrickGame
* Подсчёт очков:

  * 1 линия — 100 очков
  * 2 линии — 300 очков
  * 3 линии — 700 очков
  * 4 линии — 1500 очков
* Система уровней: каждые 600 очков увеличивают уровень, ускоряя падение фигур (10 уровней)
* Хранение рекорда в отдельном файле

## 🧠 Архитектура

Игра построена на основе **конечного автомата (КА)**, состоящего из следующих состояний:

* **Старт** — ожидание начала игры
* **Спавн** — создание текущей и следующей фигуры
* **Перемещение** — обработка ввода от пользователя
* **Сдвиг** — падение фигуры по таймеру
* **Соединение** — столкновение с землёй/другими фигурами
* **Игра окончена** — при достижении верхней строки

Диаграмма КА: `diagrams/tetris.png`

## ⌨️ Управление

| Клавиша   | Действие                    |
| --------- | --------------------------- |
| ← / A / a | Движение фигуры влево       |
| → / D / d | Движение фигуры вправо      |
| ↓ / S / s | Быстрое падение фигуры вниз |
| ↑ / Space | Вращение фигуры             |
| Enter     | Начать новую игру           |
| P / p     | Пауза                       |
| R / r     | Завершить игру              |

*Все клавиши обрабатываются независимо от регистра.*

## 📦 Установка и сборка

### Сборка проекта

```bash
make
```

### Установка

```bash
make install PREFIX=/путь/к/каталогу
```

### Удаление

```bash
make uninstall PREFIX=/путь/к/каталогу
```

### Прочие цели

```bash
make clean         # Очистка сборки
make dist          # Создание архива с исходниками
make dvi           # Генерация документации
make gcov_report   # Отчёт покрытия
```
